# Schema Version History (22 and older)

[specification-data.md](specification-data.md) の Versioning から切り出した、スキーマのバージョン 22 以下の経緯。

- 22 では（22 で商品の設定 `product_shares` を、種類つきの `share` から、比率だけの `weight` に変えた。種類 `equal`（等分）と `keep_current`（現在の比率を維持）はなくし、等分は比率 1 とした。古いアプリは古い種類として読むので断る。古い版のファイルは、読み込むときに変換する（`migrate.rs`）: `weighted` は比率を残し、`equal` と `keep_current` は設定を消す（既定の比率 1 になる）。比率 1 の `weighted` も消す。書き出しの `product_targets.csv` から `targeting` の列をなくした）。21 では（21 で「すべて」用の「売買に加えない」一覧 `excluded_all` を足した。古いアプリは口座の一覧で「すべて」を提案してしまうので断る。古い版のファイルは、`excluded` と同じ内容で始める（`migrate.rs`）。`SetExcluded` の `all` で選ぶ）。20 では（20 でカテゴリの `targeting` と記録の `weight` を廃止し、商品の持ち方 `product_shares` に置き換えた。古いアプリは持ち方を読めず全商品を等分で提案してしまうので断る。古い版のファイルは、読み込むときに変換する（`migrate.rs`）: カテゴリが「比率を指定」なら、その商品に、記録の比率の合計（比率のない商品は等分。上限を超えたら上限）を `weighted` として、「現在の比率を維持」なら `keep_current` として、4 つのモードすべてに同じ設定を置く。「自由」「等分」は何も置かない（既定が等分）。そのあと両方の項目を消す。`holdings.csv` から `relative_weight` の列、`categories.csv` から `product_targeting` の列をなくし、`product_targets.csv` を足した。19 で口座の「買える商品」`tradable` を廃止し、「売買から除く商品」`excluded` に統合した。古いアプリは `tradable` がないものを「すべて買える」と読み、除いた商品まで売買する提案を出してしまうので断る。古い版のファイルは、読み込むときに変換する（`migrate.rs`）: 加える = `tradable` に入っている（または `tradable` が未設定）かつ `excluded` にない。つまり新しい `excluded` は、旧 `excluded` に、`tradable` が設定された口座の `tradable` にない全商品を足したもの。`accounts.csv` から `tradable_product_ids` の列をなくした。18 で口座の戦略 `strategy` を足した。古いアプリは戦略を無視してカテゴリの目標で提案してしまうので断る。古い版のファイルは、`portfolio` のものとして読む（変換するものはない）。`accounts.csv` に `strategy`・`strategy_products` の 2 列を足した。17 で全体リバランスの対象口座 `settings.target_account` をなくした。「すべて」のタブは全口座をまたぐので、古いアプリは存在しない対象口座を読んでしまうため断る。古い版のファイルは、読み込むときにこの設定を捨てる（`migrate.rs`）。書き出しの `settings.csv` からも、対象口座の 2 行を除いた。16 で口座の「売買から除く商品」`excluded` を足した。古いアプリは除いた商品を売買する提案を出してしまうので断る。古い版のファイルは、`excluded` が空のものとして読む（変換するものはない）。15 で読み取りの評価額の列 `evaluation_column`・`evaluation_part` を足した。古いアプリは評価額の照合をせず 数量 × 価格 を値にしてしまうので断る。変換するものはなく、足したものがない読み取りはそのまま動く。14 で口座の種別をレコードへ移し、追加の種別 `custom_types` を足した。古いアプリは口座の種別の項目を必要とするので断る。古い版のファイルは、読み込むときに変換する（`crates/portfolio/src/migrate.rs`）。9 でリンクのメニューのクリックを、10 でレシピのプリセットへの参照を、11 でグループとカテゴリのグループを、12 でレシピのカード読み取りを、13 で読み取りの種別の列と規則を足した。足したものは、古いアプリが誤って読まないよう、古いアプリが断る版にした）。商品の相対比率を口座ごとの記録に移したのは 8（20 でさらに `product_shares` へ移した）で、8 より古いファイルは、変換せずに断り、ファイルには触れない（`MIN_SCHEMA_VERSION`）。新しい版のファイルも、古いアプリが読まずに断るので、知らない項目を黙って消すことがない。
